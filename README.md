# 🏥 DocAppoint Server

Backend API for a doctor appointment booking system built with **Node.js, Express, and MongoDB**. It supports JWT authentication using JWKS.

---

## 🚀 Features

- Doctors listing & details
- Create, read, update, delete appointments
- JWT protected routes
- MongoDB integration

---

## 🛠 Tech Stack

- Node.js
- Express.js
- MongoDB (Native Driver)
- JWT (JOSE / JWKS)
- CORS, dotenv
